# Готовая сборка Windows через GitHub

Это исходники 10v12 v1.7 с настроенной GitHub Actions. Готовых EXE в архиве нет: их создаст GitHub.

1. Создай репозиторий на github.com. Можно Private. Пароли и токены никому не отправляй.
2. Распакуй архив. Загрузи СОДЕРЖИМОЕ папки проекта в корень репозитория: package.json, main.cjs, app и остальные файлы. Не загружай сам ZIP.
3. Обязательно сохрани путь `.github/workflows/build-windows.yml`. Если браузер не загрузил скрытую папку `.github`: нажми Add file → Create new file, введи `.github/workflows/build-windows.yml`, скопируй содержимое одноимённого файла из архива и нажми Commit changes.
4. Открой Actions → Build Windows EXE → Run workflow → Run workflow. При необходимости сначала включи Actions для репозитория. В некоторых аккаунтах потребуется доступная квота GitHub Actions.
5. Дождись зелёной галочки. Открой завершённый запуск → Artifacts → 10v12-Windows-x64. Скачай ZIP и распакуй.
6. `10v12-1.7.0-x64-setup.exe` — установщик. `10v12-1.7.0-x64-portable.exe` — запуск без установки. Для них не нужно устанавливать Node.js.

Если появилась красная галочка, открой упавший шаг и пришли текст ошибки. Не присылай секреты.

## Версии Minecraft

Каталог загружается при открытии приложения из официального version_manifest_v2.json Mojang и обновляется кнопкой «Обновить каталог». Есть поиск и фильтр: релизы, снапшоты, old_beta, old_alpha. Для показа всех типов выбери «Все типы». Внизу окна доступен полный загруженный список; карточки показывают первые 80 результатов поиска.

Это все записи, опубликованные Mojang в этом каталоге, а не буквально все существовавшие сборки. Bedrock, неофициальные сборки, Forge и произвольные модпаки сюда не входят. Visuals — только 1.21.1. Наличие в каталоге не гарантирует запуск: историческим версиям могут потребоваться старые библиотеки, особенности ОС и ручная настройка. Будущие версии с новым форматом запуска или неподдерживаемой Java потребуют обновления лаунчера.

Java 8, 16, 17, 21 или 25 выбирается по данным версии и устанавливается отдельно при необходимости. Если Mojang не указал Java, используется историческое правило для релизов и Java 8 для старых сборок. Для первого запуска нужны интернет и свободное место. Minecraft не включён в EXE и скачивается отдельно. Для Microsoft-входа нужна лицензия Java Edition. Локальный профиль не даёт права на игру и не обходит проверку лицензии серверов.

## Важно

Не открывай один и тот же мир в более старой версии без резервной копии: данные могут быть повреждены. Каталог использует общую папку сохранений лаунчера.

EXE не подписан цифровой подписью, поэтому Windows может показать предупреждение о неизвестном издателе. Не отключай Defender. Если он обнаружил угрозу, остановись и проверь название угрозы и журнал сборки.

В этой среде выполнены только синтаксические и локальные тесты. Загрузка зависимостей, workflow GitHub, сборка Windows, вход Microsoft и реальный запуск Minecraft не проверены. Зависимости устанавливаются по диапазонам версий; после первой успешной сборки рекомендуется сохранить созданный package-lock.json в репозиторий и перейти на npm ci для воспроизводимости.
