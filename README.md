# 10v12 · 1.6.0

Независимый лаунчер Minecraft: Java Edition с русским интерфейсом.
Тёмная тема, авторский voxel-пейзаж, фиолетовый / мятный / голубой акцент,
выбор релиза, память, Java, полноэкранный режим и журнал состояния.

## Что это

Исходный проект настольного приложения Electron, НЕ готовый установщик EXE.
Функции игрового запуска и Microsoft подключены к minecraft-launcher-core и msmc.
Проверены интерфейс, синтаксис, локальный профиль и передача настроек в тестовый
загрузчик. Авто-Java проверена на локальных тестовых архивах и симуляции Windows:
выбор версии, скачивание, SHA-256, реальная распаковка tar, кэш, ошибки и очистка.
Реальная загрузка Temurin из интернета, распаковка на Windows, Microsoft-вход,
Minecraft и сборка установщиков в этой среде НЕ проверялись.
Это исходный проект, а не подписанный production-релиз.

## Новое в 1.6: и свой ПК, и отдельный сервер

**«Друзья» → «Добавить»** теперь предлагает три типа: **LAN**, **мир через VPN**,
**отдельный сервер**. Старые записи 1.5 автоматически читаются как LAN.
Это локальный список адресов, а не облачные друзья Xbox/Microsoft.

### Друзья в разных городах — мир на твоём ПК

1. На обоих ПК настройте одну виртуальную сеть. Например, Radmin VPN для Windows:
   один создаёт сеть, второй подключается по имени и паролю. VPN устанавливается
   отдельно; лаунчер его не включает и не создаёт сети сам.
2. Открой одиночный мир Minecraft → ESC → Открыть для сети. Посмотри порт в чате.
3. В лаунчере «Друзья» → **Мир через VPN → Настроить приглашение**.
   Выбери именно VPN-адаптер (например, 26.x.x.x у Radmin), введи порт из чата,
   скопируй адрес и отправь другу. Не пересылай пароли сети публично.
4. У друга: Добавить → **Мир друга через VPN** → VPN-IPv4 хозяина + порт из чата,
   одинаковая версия Minecraft → сохранить → Присоединиться.
5. Ты должен оставаться в мире, а VPN — работать на обоих ПК. Поиск LAN через VPN
   не гарантирован, поэтому используйте ручной адрес.

### Отдельный сервер — без запущенной клиентской игры хозяина

- Уже есть Minecraft-хостинг? **Добавить сервер** → его IPv4/латинский домен,
  явный порт (обычно 25565, но бери из панели), нужная версия → Присоединиться.
- Свой Vanilla-сервер: **Как создать свой → Открыть набор запуска**. Лаунчер
  скопирует server-kit в отдельную папку данных и откроет её. Он НЕ запускает
  сервер и не принимает EULA за тебя.
- В Windows запускай START-SERVER-WINDOWS.cmd, на Linux `node start.cjs`.
  Нужен Node.js 22+. После явного согласия с EULA загрузятся официальный сервер
  Mojang и подходящая Java. По умолчанию — Vanilla 1.21.1, 2 ГБ RAM, порт 25565.
- В консоли сервера внеси вас в белый список: `whitelist add ТвойНик` и
  `whitelist add НикДруга`. Проверка аккаунтов включена; локальный профиль не
  обходит её. Для остановки введи `stop` и дождись сохранения.
- Данные сервера отделены от одиночных миров: `%LOCALAPPDATA%/10v12-dedicated`
  (Windows) или `~/.local/share/10v12-dedicated` (Linux/macOS).
- Для твоего ПК через VPN передай VPN-IP и порт СЕРВЕРА (не порт из чата LAN).
  Для VPS/хостинга используй выданный публичный IPv4/домен и порт.
- **24/7 не предоставляется лаунчером.** Нужен постоянно работающий ПК/VPS или
  Minecraft-хостинг. VPN, публичная маршрутизация/CGNAT, firewall, автозапуск
  и резервные копии настраиваются отдельно. Покупок и открытия портов нет.

Подробная инструкция и перенос существующего мира: **server-kit/README.md**.
Поддерживаются IPv4 и латинские домены, не IPv6 и не автоматический DNS SRV.
Набор создаёт Vanilla, не сервер с модпаком. Клиентский Visuals сохранён.

Проверки выполнены на имитации сети/JAR и загрузчика: формы, сохранение,
launch-параметры, EULA, контрольная сумма/размер, кэш и сохранность мира.
**Настоящая загрузка/запуск сервера, VPN и игра между городами не проверялись.**

## Новое в 1.5: друзья в одной сети

Вкладка **«Друзья»** (иконка двух людей) работает с обычным Minecraft LAN.
Это локальный список имён и адресов, НЕ сервис Microsoft/Xbox Friends: нет
заявок, онлайн-статусов и облачного хранения. С 1.6 отдельные режимы VPN и
интернет-сервера поддерживаются, как описано выше.

### Как пригласить друга к себе

1. Вы оба подключаетесь к одной Wi-Fi / Ethernet-сети. Не гостевой изолированной сети.
2. Хозяин запускает Minecraft и открывает нужный одиночный мир.
3. В игре: ESC → **Открыть для сети** → **Открыть мир для сети**.
4. В чате появляется порт (например, 51234). Оставь мир открытым.
5. В лаунчере: **Друзья → Пригласить в мой мир**. Выбери IPv4 нужного
   сетевого адаптера, введи порт из чата и нажми **Скопировать адрес**.
   При нескольких интерфейсах не выбирай VPN/виртуальный адаптер вместо общей сети.
6. Отправь другу адрес вида `192.168.1.12:51234` в вашем обычном мессенджере.
   Сам лаунчер сообщения друзьям не отправляет.
7. Друг в своём лаунчере нажимает **Друзья → Найти**. Если мир объявляется в LAN,
   он появится в «Миры рядом». Версию узнай у хозяина: LAN-объявления её не содержат.
   Внизу выбери ту же версию и нажми **Присоединиться**.
8. Если поиск не помог: **Добавить** → имя друга, IPv4 и порт в отдельных полях,
   версия игры → сохранить → **Присоединиться**. Не вставляй http:// или порт в поле IPv4.

Кнопка «Пригласить» показывает инструкцию, но не открывает мир за тебя.
Кнопка «Присоединиться» запускает Minecraft с адресом мира. Лаунчер не может
проверить факт успешного входа — результат и возможные ошибки показывает игра.
Если Minecraft у друга уже открыт, второй запуск заблокирован: **Копировать** →
в Minecraft «Сетевая игра → Прямое подключение» → вставить адрес.

У всех должна быть одна версия Java Edition и совместимые моды. Обычный LAN-мир
проверяет игровые сессии: для надёжного подключения используйте разные Microsoft-
аккаунты с Minecraft. Локальный профиль по нику не отменяет эту проверку; при
«Недействительная сессия» нужно войти в Microsoft, а не отключать защиту.
Не используй одинаковые игровые ники. Ограничения семейного аккаунта на
мультиплеер тоже действуют.

Порт может меняться после закрытия/повторного открытия мира. Старый адрес
в сохранённых друзьях не обновляется сам: удали старую запись и сохрани новый
или снова найди мир. После закрытия мира подключиться к нему нельзя.

### Поиск, приватность и ограничения

- Кнопка «Найти» около 4,5 секунд слушает стандартные LAN-объявления Minecraft:
  UDP 4445, multicast 224.0.2.60. Это пассивный поиск, НЕ сканирование портов.
  Фонового поиска нет; сокет закрывается после результата/ошибки/таймаута.
- Список найденного — снимок объявления, не гарантированный онлайн-статус.
  Поддерживаются до 32 найденных миров, до 30 сохранённых друзей.
- Режим LAN — частные IPv4: 10/8, 172.16/12, 192.168/16, 169.254/16.
  В 1.6 для VPN-IPv4 или публичного IPv4/домена выбери отдельный тип.
  IPv6, имена компьютеров без домена и автоматические туннели не поддерживаются.
- Устройство может блокировать multicast, даже если ручное подключение работает.
  Проверь разрешение Java для **частных сетей** в брандмауэре, Wi-Fi client isolation,
  гостевую сеть и сетевой адаптер. Не отключай брандмауэр целиком и не открывай
  порты роутера для игры в одной сети.
- Имена/адреса хранятся только в `friends.json` рядом с `settings.json`, не в облаке.
  В буфер обмена адрес попадает только по нажатию «Копировать».
- В браузерном предпросмотре нет сетевого поиска или запуска игры. Его список
  хранится отдельно в localStorage и не переносится в настольное приложение.
- Нужные launch-параметры передаются через quickPlay Minecraft Launcher Core:
  multiplayer для 1.20.1/1.21.1, legacy для 1.19.4.

**Проверено:** локальная валидация/сохранение, разбор и имитация UDP-объявлений,
таймаут/закрытие сокета, параметры запуска на заглушке и интерфейс 1320/390 px.
**Не проверено:** настоящее подключение двух компьютеров и реальный вход в мир
Minecraft. Сетевой успех зависит от игры, аккаунтов и настроек вашей сети.

## Новое: панель внутри игры на Right Shift (экспериментально)

1. Обнови ВСЕ файлы проекта из архива, сохрани node_modules.
2. Запусти лаунчер и выбери Minecraft **1.21.1**.
3. В «Настройки» включи **10v12 Visuals · Right Shift**, нажми **Сохранить настройки**.
4. Войди через Microsoft или по нику и нажми **Играть**.
5. На первом запуске скачиваются JDK 21 и Gradle, собирается Fabric-мод,
   устанавливаются Fabric Loader и Fabric API. Интернет и около 4 ГБ свободного
   места обязательны. Первая подготовка может занять 5–15 минут или больше.
6. Открой мир и нажми **правый Shift** (не левый). ESC / правый Shift закрывает панель.

**Это исходный мод, а не заранее собранный и проверенный JAR.** В этой среде
нет Fabric-зависимостей и сетевой Gradle-сборки: компиляция против настоящего Minecraft, миксины, запуск
Fabric и отрисовка внутри игры НЕ проверялись. Подготовка выполняется на твоём ПК;
сборка может потребовать исправления по её журналу. Синтаксис Java дополнительно
проверен локальным компилятором с тестовыми заглушками API; это не заменяет проверку
против реальных Minecraft/Fabric-зависимостей. Файл `panel-design-preview.png` — макет,
не скриншот запущенного Minecraft; шрифт в игре будет стандартным Minecraft.

## Новое в 1.4: лёгкий рендер и полезный HUD

- HUD рисует готовые строки: обновление данных 4 раза/сек, инвентаря и брони — 2 раза/сек. Обхода инвентаря, форматирования времени и измерения строк в каждом кадре нет.
- Один общий фон HUD вместо отдельных скруглённых плашек. Углы меню рассчитаны заранее; геометрия пересчитывается при изменении окна, а не каждый кадр.
- Декоративные эффекты выключены по умолчанию. После обновления старого конфига включается лёгкий пресет.
- Аура и след используют общий бюджет: не более 4 частиц/сек в лёгком режиме, 10 в обычном. При FPS ниже 45, минимальных частицах и в меню новые частицы не создаются. Уже созданные частицы исчезают естественно.
- Это оптимизация кода нашего мода, не замена Sodium. Реального замера FPS и теста Minecraft здесь не было — конкретный прирост не гарантирован.

Четыре раздела на правый Shift:
- **Интерфейс:** тег, FPS, координаты, точка прицела, часы, WASD + Space/Shift.
- **Изображение:** FOV 70–110, яркость 0–100%, покачивание, частицы Minecraft, ограниченные аура и след.
- **Инфо HUD:** проценты прочности четырёх частей брони, тотемы в инвентаре/второй руке, свободные основные слоты, предупреждение о низком HP с порогом 2–10 HP (с учётом поглощения).
- **Оформление:** шесть палитр (лаванда, мята, небо, розовый, янтарь, монохром), лёгкий режим, лёгкий пресет, сброс позиций. В лёгком режиме декор меню подавляется даже при включённых переключателях.
- **Редактор HUD:** «Инфо HUD» → «Редактор HUD» → перетащи информационный блок или клавиши. R сбрасывает позиции, ESC сохраняет. Отображаются два независимых блока; отдельные строки внутри инфоблока не перетаскиваются.
- Новые дополнительные функции выключены до включения пользователем. Нет шейдеров, размытия, ESP и тяжёлого сканирования сущностей.
- Настройки: `minecraft/config/10v12-visuals.json`; FOV, яркость и другие стандартные опции — `options.txt`.
- TAB выбирает карточку, ENTER/ПРОБЕЛ переключает, стрелки меняют значение, цифры 1/2/3/4 меняют раздел. Ползунки перетаскиваются.
- Панель и редактор ставят одиночный мир на паузу; на сервере мир не останавливается.
- Это оригинальное оформление, а не копия Pulse Visuals / Delta. Проверяй правила сервера перед использованием модов.

Обычный Vanilla-режим и автоматическая Java сохранены. Если подготовка мода
не удалась, отключи переключатель Visuals, сохрани настройки — игра запустится
в Vanilla. Ни миры, ни системная Java не удаляются.

Журнал сборки: `visuals-build.log` в папке данных приложения (рядом с minecraft).
Не устанавливай второй Fabric API поверх автоматически установленного: версии могут конфликтовать.
Перед установкой любых модов делай резервную копию миров и проверяй правила серверов.

## Обновление с 1.0 / 1.1 / 1.2 / 1.3 / 1.4 / 1.5

1. Закрой лаунчер и дождись завершения игры.
2. Скопируй СОДЕРЖИМОЕ папки `10v12` из нового архива в прежнюю папку проекта
   (ту, где лежит `package.json`), согласись на замену файлов.
3. Не удаляй `node_modules` и `package-lock.json`: npm-зависимости не изменились.
4. Запусти `START-WINDOWS.cmd`. Войди как раньше и нажми «Играть».
5. Java 25 удалять не нужно. Даже если в старых настройках выбран путь к ней,
   версия 1.2 сама перейдёт на совместимую Java.

Игровая папка и миры остаются в прежнем каталоге данных приложения.
При первом запуске Visuals новая версия исходников собирается автоматически; JDK и Gradle берутся из кэша. Minecraft повторно удалять/скачивать не требуется, если файлы уже находятся в той же игровой папке.
Старый `10v12-visuals-1.0.0.jar` автоматически переносится из `mods` в `mod-backups` рядом с игровой папкой после успешной установки нового. Другие моды не удаляются.
Весь новый код, включая `java-runtime.cjs`, должен быть скопирован; не заменяй только HTML.

## Быстрый старт — Windows

1. Распакуй архив в обычную папку, например `C:\Games\10v12`.
2. Установи Node.js LTS (https://nodejs.org), затем заново открой терминал.
3. Java вручную устанавливать НЕ нужно. Подключи интернет и оставь примерно 1 ГБ
   свободного места для архива и распаковки. Системная Java 25 не мешает.
4. Дважды нажми `START-WINDOWS.cmd`. При первом запуске установятся зависимости npm.
   Или открой терминал в этой папке и выполни:

   ```sh
   npm install
   npm start
   ```
5. Оставь поле своего пути к Java пустым: режим автоматический. Если путь уже
   задан и версия не подходит, лаунчер тоже перейдёт к автоматическому подбору.
6. Нажми «Твой аккаунт» и выбери один из двух способов:
   - **Microsoft** — аккаунт с приобретённой Minecraft: Java Edition и игровым профилем.
     Для некоторых аккаунтов потребуются разрешения Xbox / семейные настройки.
   - **По нику** — введи 3–16 символов (латиница, цифры, `_`) и нажми «Играть по нику».
     Аккаунт и пароль не нужны. Это локальный профиль, не Microsoft-авторизация.
7. Выбери версию → «Играть». При необходимости 10v12 сначала скачает и установит
   подходящую Java, затем подготовит Minecraft. Не закрывай лаунчер до завершения.

На macOS / Linux: те же `npm install` и `npm start`, Java тоже подбирается автоматически.
Поддерживаются x64 и ARM64; Linux — с glibc и `/usr/bin/tar`. Для Windows нужен
встроенный Windows PowerShell с Expand-Archive. На Linux не запускай Electron
от root и не отключай sandbox.

## Предпросмотр без установки

Открой `app/index.html` в браузере. Можно переключать страницы, выбирать версии,
менять и сохранять настройки предпросмотра, открыть окно аккаунта.
Браузер НЕ запускает Java, не скачивает игру и не входит в Microsoft;
он показывает явное уведомление о режиме предпросмотра. В нём можно создать
локальный профиль для проверки интерфейса — запуск игры по-прежнему недоступен.
Настройки предпросмотра отделены от настроек настольного приложения.

## Поддержка

- Только Vanilla, только релизы 1.21.1, 1.20.1 и 1.19.4. Это не список самых новых релизов.
- Minecraft 1.21.1 — Java 21. Minecraft 1.20.1 / 1.19.4 — Java 17.
- Авто-Java: Temurin 21 для 1.21.1; Temurin 17 для 1.20.1 / 1.19.4.
- Порядок: совместимый свой путь → проверенный кэш 10v12 → совместимая Java из PATH
  → загрузка подходящего Temurin с официального API Adoptium и релизов GitHub.
- Обычно скачивается JRE, при отсутствии сборки для платформы — JDK.
- Перед распаковкой проверяются размер и SHA-256 по данным API, после — версия
  исполняемого файла. Файлы устанавливаются только после успешной проверки.
- Локальная Java хранится рядом с `minecraft`, в папке `runtime` внутри данных
  приложения; не меняет PATH, JAVA_HOME, реестр и установленную системную Java.
- Повторные запуски используют кэш без повторного скачивания Java. При смене
  1.21.1 на 1.20.1 / 1.19.4 при необходимости скачивается отдельная Java 17.
- Патч-версия Temurin выбирается при первой установке; фонового автообновления JVM нет.
- При ошибке скачивания/проверки незавершённые временные файлы удаляются.
  Если принудительно закрыть приложение/выключить ПК, временная папка `.install-*`
  может остаться; её можно удалить из `runtime` при закрытом лаунчере.
- Файлы Minecraft скачивает minecraft-launcher-core; они не включены в архив.
- Лимит памяти: 2–16 ГБ, с резервом минимум 2 ГБ для ОС. На слабом компьютере
  снизь память и закрой другие программы. Требуется 64-битная JVM.
- Файлы в отдельной папке приложения: Windows `%APPDATA%\10v12-launcher\minecraft`,
  macOS `~/Library/Application Support/10v12-launcher/minecraft`,
  Linux `~/.config/10v12-launcher/minecraft` (может зависеть от XDG_CONFIG_HOME).
  Кнопка папки в правом верхнем углу открывает точный путь.
- При переключении версии общая папка saves сохраняется: обязательно делай резервные
  копии миров, не открывай новый мир старой версией игры.
- Статус «Манифест установлен» означает наличие JSON версии, а не полную проверку файлов.
  Недостающие файлы проверяются загрузчиком при запуске.
- Процент относится к текущему этапу; между этапами может начинаться заново.
- Есть локальный вход по нику (offline-профиль) и отдельный вход Microsoft.
- Локальный режим предназначен для одиночной игры и серверов, которые сами разрешают
  вход без проверки лицензии. Он не подтверждает владение игрой и НЕ обходит проверку
  лицензии Microsoft, Realms или серверов с online-mode=true. Скины и сервисы Microsoft
  для локального профиля не предоставляются. Соблюдай условия использования Minecraft.
- Первый запуск локального режима всё равно требует интернета для скачивания файлов.
  Полностью автономный запуск уже скачанной игры отдельно не проверялся.
- UUID локального профиля стабилен и совместим с Java OfflinePlayer: зависит от точного
  ника и его регистра. Не меняй ник/регистр без резервной копии миров: инвентарь и права
  могут определяться UUID. Microsoft и локальный профиль с одним ником — разные личности.
- Fabric автоматически готовится только для 10v12 Visuals на 1.21.1. Нет Forge, менеджера модпаков, обновлятора лаунчера и телеметрии.
- Если сессия истекла, выйди из аккаунта и войди снова.
- Авторизация хранится только в памяти. После закрытия приложения нужен повторный вход.
  Кэш входа Microsoft на самом компьютере может управляться Microsoft / системным браузером.
- Пароли и токены не передаются в интерфейс и не записываются в журнал.
- Закрытие лаунчера не предназначено для принудительного завершения Minecraft.

## Если что-то не работает

**npm не найден:** установи Node.js LTS и заново открой терминал.

**Ошибка npm install:** нужен интернет и доступ к npm и серверам загрузки Electron.
В архив намеренно не включены node_modules и lockfile: версии диапазонные;
после первой успешной установки сохрани package-lock.json для воспроизводимости.

**Не открывается Microsoft / вход отклонён:** проверь интернет, лицензию Java Edition,
Xbox-профиль и семейные разрешения. Вход обрабатывает сторонняя библиотека msmc;
его работоспособность зависит от текущих правил Microsoft. При изменениях API
может понадобиться обновление / адаптация библиотеки. Не вводи пароль в чат
или поля настроек лаунчера. Авторизация на этой сборке не была проверена.

**Найдена Java 25:** в 1.2 это не ошибка. При нажатии «Играть» лаунчер подберёт
и при необходимости скачает Java 21 / 17 сам. Путь к Java 25 можно оставить или очистить.

**Не скачивается Java:** проверь доступ к `api.adoptium.net`, `github.com` и серверам
GitHub Release Assets, свободное место и права записи в данные приложения.
Не отключай защиту Windows или проверку HTTPS. После исправления нажми «Играть» снова.
Для JRE загрузка обычно меньше, чем для JDK; скорость зависит от сети.

**Ошибка контрольной суммы:** архив не запускается. Повтори загрузку; если ошибка
сохраняется, проверь сеть/прокси. Не обходи проверку SHA-256.

**Не распаковывается на Windows:** проверь, доступен ли Windows PowerShell и команда
Expand-Archive. Внешний архиватор не требуется. Для путей с пробелами и апострофами
используются переменные окружения, путь не вставляется в команду PowerShell.

**Ручная Java:** при желании укажи путь к `bin/javaw.exe` (Windows) или `bin/java`
(macOS/Linux), не папку. Поддерживаются Java 21 и 17 по выбранному Minecraft-релизу.

**Игра закрывается:** снизь RAM, проверь Java и видеодрайверы. Журнал интерфейса
показывает состояния, а не полный консольный вывод игры. Отчёты Minecraft смотри
в папке игры (`crash-reports`, `logs/latest.log`); перед публикацией удали личные данные.

## Сборка установщика

После `npm install`:

```sh
npm run dist:win    # Windows → dist/10v12 Setup 1.6.0.exe
npm run dist:linux  # Linux → AppImage
npm run dist:mac    # macOS → DMG
```

Собирай на целевой ОС. Подпись Windows, Apple signing и notarization не настроены;
неподписанное приложение может вызывать предупреждение ОС. Не отключай защиту
системы: сначала проверь исходники и зависимости. Сборка не содержит Java и самой игры.

## Локальные LAN-тесты

`npm run test:server` проверяет подготовку выделенного сервера на синтетическом JAR.
`npm run test:lan` проверяет модуль друзей на встроенных средствах Node.js,
без настоящего поиска или запуска Minecraft. Он не заменяет тест на двух ПК.

## Структура

- main.cjs — Electron, конфигурация, Java, Microsoft / локальный вход, запуск игры.
- lan-friends.cjs — список подключений LAN/VPN/сервер, IPv4/домен/порт и quickPlay.
- server-kit/ — независимый набор запуска Vanilla-сервера с авто-Java и EULA.
- app/friends.js — интерфейс друзей и приглашений.
- java-runtime.cjs — автоматическая загрузка, проверка, установка и выбор Temurin.
- visuals-setup.cjs — подготовка JDK, Gradle, сборка и установка клиентского Fabric-мода.
- visuals-mod/ — исходники мода Minecraft 1.21.1, Yarn build.3, Fabric Loader 0.16.10, Fabric API 0.102.1.
- local-profile.cjs — проверка ника и стабильный OfflinePlayer UUID.
- preload.cjs — узкий IPC-мост; Node.js в renderer отключён, sandbox включён.
- app/index.html, style.css, renderer.js — интерфейс без CDN и сторонних шрифтов.
- app/assets/world.jpg — сгенерированное для проекта изображение; не официальный арт Minecraft.

Название 10v12 — пользовательское. Проект не связан с Mojang или Microsoft.
Minecraft и его товарные знаки принадлежат правообладателям. Локальный профиль
не выдаёт лицензию на игру и не заменяет её для лицензионных сервисов.
