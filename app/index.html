ТЫ — ХОЗЯИН МИРА

Позови к себе

Выберите общую Wi-Fi/Ethernet-сеть.

  1. Открой мир MinecraftОдиночная игра → твой мир.
  2. Разреши игру по сетиESC → «Открыть для сети» → «Открыть мир для сети». В чате появится порт.
  3. Поделись адресомВыбери свой IP и введи этот порт ниже. Мир должен оставаться открытым.

При нескольких адресах выбери адаптер общей сети Wi-Fi / Ethernet.

Отправь адрес другу. Он добавит тебя в этой вкладке или введёт адрес в Minecraft → «Сетевая игра» → «Прямое подключение».

СВОЙ МИР БЕЗ ПРИВЯЗКИ К ИГРОКУ

Отдельный сервер

Используй готовый Minecraft-хостинг или подготовь Vanilla-сервер нашим набором. Он скачает официальный серверный JAR и подходящую Java после принятия EULA.

  1. Подготовь компьютер или VPSНужны Node.js 22+ и место для мира. Режим 24/7 обеспечиваешь ты или хостинг.
  2. Открой набор запускаВ Windows запусти START-SERVER-WINDOWS.cmd из открывшейся папки. На Linux: node start.cjs. Прими EULA, затем добавь ваши ники: whitelist add Ник.
  3. Укажи адрес сервераВведи выданные хостингом IPv4/домен и порт. Для своего ПК используй VPN-IP. Доступ через публичный IP требует отдельной настройки сети.

Лаунчер не покупает VPS, не устанавливает VPN и не открывает порты роутера. Проверка Microsoft-сессии и белый список сервера включены. Данные сервера хранятся отдельно от одиночных миров.

Чтобы всё сошлось

Одинаковая версия Minecraft и разные игровые ники. Для LAN нужна общая сеть, для VPN — общая VPN-сеть; для сервера — доступный адрес. Обычный LAN-мир проверяет аккаунты: локальный профиль без Microsoft может не пройти проверку сессии. Если игра уже запущена, используй «Копировать» и прямое подключение внутри Minecraft.

Не видно мир? Проверь гостевую сеть, изоляцию клиентов и разрешение Java для частной сети в брандмауэре. Не отключай защиту целиком.
