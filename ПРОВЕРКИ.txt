ПРОВЕРКИ 10v12 1.6.0 / Visuals 1.1.0

Проверено локально:
- Синтаксис Node.js, JSON; компиляция Java 21 против тестовых заглушек API.
- Переключатели, клавиатура, ползунки, 4 раздела, 6 палитр.
- Инвентарь, тотемы (включая вторую руку), проценты брони, HP с поглощением.
- 120 кадров HUD: без обходов инвентаря и без измерений ширины текста
  (счётчики тестовых API; это НЕ замер FPS).
- Обновление инвентаря раз в 10 тиков; нет обходов в меню.
- Общий бюджет ауры/следа 4 или 10 за 20 тиков; отсечка ниже 45 FPS.
- Миграция лёгкого пресета; редактор: перетаскивание, сброс.
- Установщик с имитацией сети/Windows/Gradle: авто-JDK, контрольные суммы,
  кэш, пересборка, резервная копия старого собственного JAR;
  сторонние моды не трогаются.
- Передача параметров Vanilla/Fabric и двух типов профиля (заглушки).
- 11 проверок авто-Java на локальных тестовых архивах и имитации Windows.
- UI лаунчера 1320px/390px: переключатель, сохранение, ограничение 1.21.1,
  отсутствие ошибок JS и горизонтального переполнения.
- Макеты 4 разделов и редактора отрендерены и просмотрены.

НЕ проверено: сборка с настоящими Minecraft/Fabric-зависимостями,
реальный запуск Minecraft и миксинов, производительность в игре,
сетевые Microsoft/Temurin-загрузки, реальная установка Windows.
Архив содержит исходники; JAR должен собраться на ПК пользователя.

НОВОЕ В 1.5 — ДРУЗЬЯ LAN:
- Валидатор частных IPv4/порта/версии, защита от передачи произвольных launch-аргументов.
- Сохранение friends.json: очередь параллельных записей, атомарная замена,
  удаление, повторное чтение; повреждённый файл не перезаписывается.
- Имитация multicast: разбор MOTD/порта, дедупликация, фильтр частных IPv4,
  таймаут, ошибки bind, отсутствие адаптера, закрытие сокета.
- MCLC-заглушка: quickPlay multiplayer/legacy, выбор Java и версии,
  запрет второго запуска, отклонение публичного IP.
- Playwright 1320/390: добавление/удаление друга, ошибка формы, модальное окно,
  Escape, поиск/результат/ошибка, адрес копирования и параметры присоединения,
  отсутствие JS-ошибок/переполнения, браузерный режим без настоящего поиска.
- Скриншоты пустого/заполненного списка, поиска и формы просмотрены.
- Новые основные пары текста имеют AA-контраст; поля/кнопки — контраст границ >=3:1.
- Авто-Java и код Visuals 1.1.0 не менялись. Регрессия установщика и UI Visuals пройдена.

Запуск автономных LAN unit-тестов: npm run test:lan (не требует npm install).
Это синтетические тесты, НЕ подтверждение успешной игры по LAN на двух ПК.
Реальные multicast, Windows firewall, авторизация и Minecraft-сессия не проверены.

НОВОЕ В 1.6 — VPN И ОТДЕЛЬНЫЙ СЕРВЕР:
- Типы LAN/VPN/server; миграция записей без mode в LAN; VPN-IPv4 25/26/100.64;
  публичный IPv4 и латинский домен; отказ при URL/порте в поле host/IPv6/инъекции.
- Шаблоны quickPlay для VPN и сервера проверены на загрузчике-заглушке.
- Playwright: режим/подсказки формы, порт 25565, сохранение публичного домена,
  VPN-запись, передача режима при запуске/копировании, выбор VPN-адаптера,
  кнопка server-kit; 1320/390 px, JS-ошибок/горизонтального переполнения нет.
- Макеты VPN-хозяина, формы VPN/сервера/ошибки, инструкции сервера и мобильного
  состояния отрендерены и просмотрены. Исправлена устаревающая ошибка ввода.
- server-kit/setup на синтетических метаданных и неисполняемом JAR:
  отказ EULA => 0 сетевых запросов; явное согласие => установка; SHA1/размер;
  повторный запуск из кэша без сети; запрет смены версии существующего сервера;
  мир и properties сохраняются; online-mode/whitelist включены, отключённая
  проверка аккаунтов блокирует запуск без самовольной правки файла;
  испорченный JAR не устанавливается, временный файл удаляется.
- npm run test:server и npm run test:lan выполняются без npm install.

Не проверено: реальный download Mojang/Temurin, серверный Java-процесс,
консоль сервера/генерация мира, Windows/VPS/firewall/VPN, игра между городами.
Набор содержит исходники и инструкции, НЕ создаёт хостинг/VPN/публичный доступ.
