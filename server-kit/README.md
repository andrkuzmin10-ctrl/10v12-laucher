# 10v12 — отдельный Vanilla-сервер

Это исходный набор запуска сервера, а НЕ оплаченный хостинг, VPN или готовая
служба 24/7. Сервер работает, пока включены его компьютер, процесс Java и сеть.
Для независимого от твоего ПК мира используй Minecraft-хостинг или свой VPS.
Лаунчер не покупает и не настраивает VPS, роутер или брандмауэр автоматически.

## Windows

1. Установи Node.js 22 LTS или новее с https://nodejs.org/ (он уже нужен лаунчеру).
2. Открой `START-SERVER-WINDOWS.cmd`. Не запускай два экземпляра одновременно. При блокировке после аварийного
   закрытия сначала убедись, что оба процесса Node/Java сервера завершены, затем
   удали только server-run.lock в каталоге данных сервера (не мир).
3. Прочитай EULA Minecraft и введи **ДА**, только если принимаешь её.
   До подтверждения сервер/Java не скачиваются и не запускаются.
4. Скачиваются официальный Vanilla server 1.21.1 и подходящая Temurin Java 21.
   Контрольная сумма/размер JAR сверяются с данными Mojang; Java проверяется SHA-256.
5. В консоли сервера введи без `/`: `whitelist add ТвойИгровойНик`, затем
   `whitelist add НикДруга`. Нужны разные действительные игровые аккаунты.
6. Для остановки введи **stop** и дождись сохранения мира/закрытия процесса.
   Не выключай компьютер и не удаляй файлы во время работы сервера.

## Где данные

- Windows: `%LOCALAPPDATA%\10v12-dedicated`.
- Linux/macOS: `~/.local/share/10v12-dedicated`.
- `server-config.json`: версия, RAM в ГБ (по умолчанию 2), начальный порт 25565.
- `game/server.properties`: действующий порт и опции. После создания этот файл
  сохраняется, а поле port в server-config не перезаписывает его.
- `game/world`: отдельный серверный мир. `game/logs/latest.log`: журнал сервера.
- `runtime`: отдельная Java. Системные PATH/Java не меняются.

Чтобы выбрать 1.20.1 или 1.19.4: после первого создания config, но ДО загрузки
сервера (можно ответить НЕТ на EULA), измени `version` в `server-config.json`.
Нужная Java 17 установится автоматически. У существующего сервера версия
автоматически не меняется: не понижай мир; сначала создай резервную копию и
отдельный каталог данных. Набор намеренно останавливается при смене версии
относительно server-install.json.

Параметры по умолчанию: online-mode=true, white-list=true, enforce-whitelist=true,
RCON/query выключены, 8 игроков, дальность 8, симуляция 6. Проверка аккаунтов и
белый список обязательны; набор не запускает сервер с выключенной проверкой.
Не публикуй RCON, не отключай firewall целиком, не давай OP незнакомым людям.

## Друг в другом городе: твой ПК через VPN

- На Windows можно использовать Radmin VPN: https://www.radmin-vpn.com/.
  Оба ставят приложение; один создаёт сеть, второй входит по имени/паролю.
  Используй уникальный пароль, сообщай его только друзьям, не пиши в публичный чат.
- Сервер остаётся запущен на твоём ПК. Друзьям передай IPv4 VPN-адаптера этого ПК
  и порт из game/server.properties (обычно 25565).
- В лаунчере Друзья → Добавить → «Отдельный сервер» → IPv4 и порт.
  Сам VPN запускается и настраивается отдельно; кнопка лаунчера не создаёт VPN.
- Для одиночного мира вместо отдельного сервера: ESC → Открыть для сети;
  у друга тип «Мир друга через VPN», VPN-IP хозяина и порт ИЗ ЧАТА (не 25565).
- Хозяин LAN-мира должен находиться в мире; отдельный сервер не требует
  запущенной клиентской игры, но его ПК всё равно должен работать.
- Поиск «Миры рядом» через VPN не гарантирован; используй ручной адрес.

## Отдельный хостинг / VPS 24/7

Самый простой способ — Minecraft-хостинг: выбери ту же версию Java Edition,
включи online-mode и whitelist, внеси ники и получи от провайдера адрес/порт.
Добавь этот адрес в лаунчер типом «Отдельный сервер».

Для собственного VPS (Linux): скопируй `start.cjs`, этот README и файл
`java-runtime.cjs` из корня проекта в одну папку, установи Node.js 22+, запусти
`node start.cjs` под обычным пользователем, прими EULA. Набор создаёт данные в
домашнем каталоге. Порт сервера TCP должен быть доступен по правилам провайдера;
разрешай только нужный игровой порт, не открывай все порты. Автозапуск/службу
и резервные копии администратор настраивает отдельно. Лаунчер не управляет VPS.

На домашнем ПК без VPN публичный доступ может потребовать публичный IPv4,
проброс TCP-порта и отдельные правила firewall. При CGNAT этого недостаточно:
нужен VPN/хостинг/публичный адрес от провайдера. Скрипт эти настройки не меняет.

Поддерживаемые адреса в лаунчере: IPv4 и латинские домены; IPv6 и DNS SRV
автоматически не обрабатываются. Вводи явный порт из панели хостинга.

## Перенос существующего мира

Останови сервер командой stop и закрой одиночную игру. Сделай резервные копии
обоих миров. Скопируй СОДЕРЖИМОЕ нужной папки saves/ИмяМира в game/world сервера
той же версии, сохранив резервную копию прежнего game/world. Не копируй мир при
работающей игре/сервере. Моды с контентом требуют совместимого сервера — этот
набор создаёт Vanilla, не Fabric/Forge-модпак. Visuals — клиентский мод.

## Проверки и ограничения

Модуль подготовки проверен на локальных синтетических метаданных/JAR:
согласие EULA, сумма, размер, кэш, отказ при смене версии, сохранение properties.
Реальная загрузка Mojang/Temurin, генерация мира, VPN и игра на двух ПК не
проверялись. Успешное создание файлов в тесте не подтверждает доступность сервера.
